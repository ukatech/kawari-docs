# 幸水 (kosui)

"幸水(こうすい)"はコンソールで動作する華和梨インタープリタです。稼動中のゴーストの華和梨と接続し、デバッグ作業を行うことも出来ます。

| ページ | 内容 |
|---|---|
| [起動方法](launch.md) | コマンドラインオプションと、インタープリタモード・デバッガモード・quiet モード |
| [検査モード (--check)](check-mode.md) | 辞書のエラーと警告を、ゴーストを動かさずに調べる |
| [操作方法](operation.md) | echo モードと command モードの切り替え、終了方法 |
| [幸水を使ったデバッグの指針](debugging.md) | 文法エラー・実行時エラー・アルゴリズムの順にデバッグする |
