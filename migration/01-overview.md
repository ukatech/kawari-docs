# Phase 7 以前からの移行ガイド

2004/02/01

Phase 8.2.0

NAKAUE.T (Meister),偽Meister (夢乃),さとー,酔狂,さくらのにえ

**\[2026/10/23追記\]**このガイドは、Phase 7以前から**Phase 8**へ移るためのものです。華和梨**Phase 9は、Phase 8 (8.2.x)の置き換えとして、そのまま差し替えて使えます**。Phase 8のゴーストは辞書を書き換えずに`shiori.dll`を差し替えるだけで動きます。Phase 8のゴーストをPhase 9に上げるだけなら、このガイドは読む必要がありません。差し替えるときの注意点は、同梱の`readme.1st`(README.md)の「華和梨8からの乗り換え」を参照してください。

華和梨Phase 8では、かつてないほど大規模な変更が行われているため、移行には、実質的に新しい栞に乗り換えるのと同等のコストがかかると見込まれます。その負担を少しでも減らすために、過去互換性を持たない重要変更点と、移行のヒントを挙げます。新しい仕様の詳細は[ユーザーズマニュアル](../grammar/00-introduction.md)を参照してください。
