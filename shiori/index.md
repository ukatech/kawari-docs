# SHIORI/SAORI インターフェース

ここまでに、ゴーストの動作記述方法については、ほぼ全て解説しました。が、肝心の「ダブルクリックイベントに対応するには？」「おすすめURLを表示するには？」などの説明を一切しませんでした。

栞としての機能については、この章でまとめて説明します。また、華和梨はSAORIとしても機能しますので、それについても併せて説明します。

## 基本

| ページ | 内容 |
|---|---|
| [コールバック](callbacks.md) | 本体からのイベント・NOTIFY の通知で最初に評価されるコールバックエントリ（`System.Callback.OnRequest` など） |
| [その他のシステムエントリ](system-entries.md) | コールバック以外のシステムエントリの一覧 |
| [栞としての華和梨](as-shiori.md) | イベント応答・リソース文字列・NOTIFY 処理の呼び分けを KIS で書く |
| [SAORIモジュールとしての華和梨](as-saori.md) | 華和梨を SAORI として使うときの引数・戻り値・ステータス |
| [SAORIモジュールの使用宣言](saori-register.md) | `saoriregist` で SAORI の使用を宣言する |
| [SAORIモジュール呼び出し](saori-call.md) | `callsaori` / `callsaorix` で SAORI を呼び出す |

## 応用編

上記を踏まえ、ゴーストの基本動作を実装する際、華和梨Phase 8ではどのように記述するのか、幾つか例を交えて紹介します。

| ページ | 内容 |
|---|---|
| [イベント](events.md) | Reference ヘッダを短い名前で参照するコマンドを定義して、イベントに応答する |
| [コミュニケート](communicate.md) | 他のゴーストに話し掛ける・話し掛けられたときに応答する |
| [自発トーク](random-talk.md) | `OnSecondChange` でカウンタを回して、一定間隔でトークする |
