# lambda

**Category:** 構文コマンド

## 書式

```
$(lambda 関数の定義)
```

## 戻り値

定義された関数の名前

## 解説

名前を付けずに関数コマンドを定義し、その名前を返す。名前は`System.Lambda.n`の形で、定義済みの関数と重ならないように自動で付けられる。関数の定義の書き方と引数の渡され方は、[function](function.md)と同じである。

返された名前をエントリに入れておき、`$(${エントリ} 引数)`のようにコマンド名として使うと呼び出せる。関数の引数に名前を渡して、呼び出し先で使うこともできる。

定義の中から、lambdaを定義した場所の`@`で始まるローカルエントリ(外側の関数の`@arg`など)は参照できない(クロージャではない)。ローカルエントリは、呼び出されたときに作られるものだけが見える。

定義した関数は自動では消えない。不要になったら[rmfunc](rmfunc.md)で削除する。

## 使用例

```
=kis
# 引数を[ ]で囲んで返す無名関数。名前がfエントリに入る
set f $(lambda $(echo [$@arg[1]]));
# 関数に名前を渡して、呼び出し先で使う
function apply $(
  echo $($@arg[1] $@arg[2]);
);
=end
$(${f} hi)        # 「[hi]」が返る
$(apply ${f} hi)  # 「[hi]」が返る
```
