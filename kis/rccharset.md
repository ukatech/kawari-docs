# rccharset

**Category:** その他

## 書式

```
$(rccharset 文字コード名)
```

## 戻り値

なし

## 解説

華和梨の出力するエラーメッセージの言語を、文字コードで指定する。指定する文字列は大文字、小文字を同一視する(case insensitive)。デフォルトは"ISO-8859-1"(いわゆる半角英文字、ほぼASCII)。それ以外には、現在の所、"`Shift_JIS`"(Phase 9.0.0以降は"UTF-8"も)だけが使える。対応していない文字コードを指定するとISO-8859-1になる。

Phase 9.0.0以降は"UTF-8"も指定でき、"`Shift_JIS`"と同じく日本語になる。

## 使用例

```
=kis
# 日本人ならやっぱり?
rccharset Shift_JIS;
=end
```
