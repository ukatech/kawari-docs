# inc

**Category:** カウンタ

## 書式

```
$(inc エントリ1 増分 上限)
```

## 戻り値

なし

## 解説

エントリ1を増分だけ加算する。増分と上限は省略可能。増分を省略した場合、1と見なす。加算した結果が上限より大きくなった場合、エントリ1の内容は上限となる。上限を省略するといつまでも加算できる。

エントリ名の指定には、[辞書操作コマンド共通の書式](dictcommon.md)を利用できる。

## 使用例

```
=kis
inc N;
# Nを1だけ増やす

inc N 5;
# Nを5だけ増やす

inc N 10 100;
# Nを10だけ増やし、結果が100より大きければNは100とする

inc N[2] 4;
# N[2]を4だけ増やす

inc N[1..-1] 2 100;
# N[0]以外のNをそれぞれ2だけ増やし、結果が100より大きければ100とする
=end
```
