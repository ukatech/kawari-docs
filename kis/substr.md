# substr

**Category:** 文字列操作

## 書式

```
$(substr 文字列1 開始位置 長さ)
```

## 戻り値

部分文字列

## 解説

文字列1の部分文字列を返す。文字列1の「開始位置+1」文字目から、「長さ」文字分を返す。位置は0オリジンである。長さは省略でき、省略した場合、開始位置から末尾までを返す。位置が負の数の場合、末尾から数えた位置になる。

Phase 9.0.0以降、位置と長さは`wchar_t`単位(Windowsではサロゲートペアは2文字分)で数える。

## 使用例

```
=kis
substr ABCDEFG 3 2;
# 「DE」を返す

substr ABCDEFG 3;
# 「DEFG」を返す
=end
```
