# mktime

**Category:** その他

## 書式

```
$(mktime 年 月 日 時 分 秒)
```

## 戻り値

1970/1/1 0:00:00(協定世界時)から指定時刻までに経過した秒数

## 解説

1970/1/1 0:00:00(協定世界時)から、引数で指定した時刻までに経過した秒数を返す。主に戻り値を`$(date %s)`の第2引数に与える。2038年以降も、1970年より前も扱える(64ビット。1970年より前は負の値になる)。年が1900より小さいときは1900として扱う。変換できないほど大きな時刻(約9.5億年を超えるもの)は-1を返す。Windows版はCランタイムの`mktime`を使わず自分で計算するので、Cランタイムの限界(1970年より前と3000年末あたりより後が変換できない)には縛られない。夏時間の切り替えで存在しない時刻(春の2:30など)は夏時間側、2回ある時刻(秋の1:30など)は先の(夏時間の)ほうとして扱う。POSIX版はOSの`mktime`を使うので、範囲はOSの`time_t`による。

## 使用例

```
=kis
# 1970/1/1 0:00:00(UTC)から2005/4/1 0:30:25までに経過した秒数を返す
mktime 2005 4 1 0 30 25;

# 2001/1/25 1:00:00から1000日後の日付を求める
# 1000日分をmktimeで求めた時刻に足して、dateの第2引数に与えている
setstr @day $(mktime 2001 1 25 1 0 0);
date "%y/%m/%d %H:%M:%S" $[ ${@day} + 1000 * 24 * 60 * 60 ];
=end
```
