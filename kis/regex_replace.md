# regex_replace

**Category:** 正規表現

## 書式

```
$(regex_replace 文字列1 パターン 置換文字列 [オプション])
```

## 戻り値

置換後の文字列(マッチしなければ文字列1のまま)。エラーのときは空文字列

## 解説

マッチした部分すべてを置換文字列で置き換える。置換文字列の中では次が使える。

- `$1` `$2` ...: そのグループにマッチした文字列
- `${名前}`, `${1}`: 名前・番号で指定
- `$&`: マッチした全体
- `` $` `` `$'`: マッチの前・後ろ
- `$$`: `$` という文字

`$` を含む置換文字列は `"..."` で囲むこと。

## 使用例

```
=kis
regex_replace "a1b22" "([a-z])([0-9]+)" "$2$1";
# 「1a22b」が返る
=end
```
