# char_at

**Category:** 文字列操作

## 書式

```
$(char_at 文字列1 インデックス)
```

## 戻り値

文字列1の「インデックス+1」文字目の文字

## 解説

指定文字列の指定した場所の1文字を返す。マルチバイト文字も1文字と数える。Phase 9.0.0以降は内部文字列が`wchar_t`であり、WindowsではU+10000以上の文字(絵文字など、サロゲートペア)は2文字と数える。インデックスは0オリジンであることに注意。

## 使用例

```
=kis
char_at 世界よ、こんにちは。 2;
# 「よ」が返る
=end
```
