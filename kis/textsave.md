# textsave

**Category:** ファイル操作

## 書式

```
$(textsave ファイル名 エントリ1 [エントリ2..])
```

## 戻り値

なし

## 解説

エントリ1、エントリ2…の全ての内容を、テキストファイル1に書き出す。セキュリティの観点から、書き出すファイル名は相対パスのみである。エントリの内容は、添え字順に評価してその結果を書き出す。ファイルに書き出す際、添え字ごとに最後に改行する。textappendとの違いは、テキストファイル1の以前の内容が残らない点である。

Phase 9.0.0以降、内容はUTF-8(BOMなし)で書き出される。Phase 8.2.9以前は`Shift_JIS`で書き出していた。

## 使用例

```
=kis
textsave highscore.dat タイトル保持者名一覧;
# highscore.datに、「タイトル保持者名一覧」エントリの内容を保存
=end
```
