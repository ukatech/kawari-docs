# regex_match

**Category:** 正規表現

## 書式

```
$(regex_match 文字列1 パターン [オプション [エントリ1]])
```

## 戻り値

文字列1のどこかにパターンがマッチすれば1、しなければ0。エラーのときは空文字列

## 解説

エントリ1を指定すると、その内容を置き換えて、マッチした部分全体、続いて括弧のグループ1、2、...を順に格納する(マッチしなかったグループは空文字列。マッチしなければエントリは空になる)。先頭からの完全一致を調べるには^と$を使う。

## 使用例

```
=kis
regex_match "key=42" "([a-z]+)=([0-9]+)" "" m;
# 1が返り、mは「key=42」「key」「42」の3単語になる
=end
```
