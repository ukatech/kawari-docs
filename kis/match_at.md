# match_at

**Category:** 文字列操作

## 書式

```
$(match_at 文字列1 パターン インデックス)
```

## 戻り値

パターンがあれば1、なければ""

## 解説

文字列中のインデックス番目(0オリジン)にパターンが存在すれば1。存在しなければ""を返す。指定省略時のインデックスは0.

## 使用例

```
=kis
match_at 芝村をやっている 村を;
# ""が返る

match_at 芝村をやっている 村を 1;
# 1が返る

match_at あーりーあーもー殺ーるーのー あー 4;
# 1が返る

match_at 我は、我である。 ジャム;
# ""が返る
=end
```
