# load

**Category:** ファイル操作

## 書式

```
$(load ファイル名)
```

## 戻り値

なし

## 解説

華和梨辞書形式ファイルを読み込む。暗号化辞書も可。ファイル名の先頭が「/」「\」またはドライブ名から始まる場合には絶対パスとみなし、それ以外の場合にはゴーストのディレクトリからの相対パスとみなす。

Phase 9.0.0以降、ファイルの文字コードは自動判定される。先頭にUTF-8のBOMがあるか、ファイル全体がUTF-8として正当ならUTF-8、そうでなければ`Shift_JIS`(CP932)として読む(従来の`Shift_JIS`辞書はそのまま読める)。暗号化行(!KAWA0000、!KAWA0001)は、ファイルにBOMがあれば復号結果をUTF-8、なければ`Shift_JIS`として読む。

## 使用例

```
=kis
load dict-flag.txt;
# dict-flag.txtを読み込む
=end
```
