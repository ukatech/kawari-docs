# 正規表現コマンド共通の仕様

**Category:** 正規表現

## 対象

`regex_match`,`regex_find`,`regex_findall`,`regex_count`,`regex_replace`,`regex_replace_first`,`regex_erase`,`regex_erase_first`,`regex_split`,`regex_escape`

## パターン

エンジンは`uka_regexp`(Unlicense)。構文と意味はPCRE2(Perl互換)に近い。文字クラス、Unicodeプロパティ(`\p{Hiragana}`など)、最短・所有量指定子、先読み・後読み、名前付きグループ、後方参照、再帰、条件分岐などが使える。`\d` `\w` `\s` `\b`とPOSIXクラス(`[[:alpha:]]`など)は、既定ではASCIIのみが対象(全角数字には一致しない)。パターンの先頭に`(*UCP)`を書くと、Unicodeのプロパティで判定される。

パターンは、辞書の単語としてもスクリプトの引数としても、**括弧を含むときは"..."で囲む**こと。括弧がそのままだと華和梨のスクリプトの構文として消えてしまう。"..."の中の`${...}`や`$(...)`は展開されないので、置換文字列の`${1}`や`${name}`も同様に"..."で囲めばそのまま渡せる。構文の詳細は`uka_regexp`のREADME.mdを参照。

## オプション

文字の並びで指定する(省略または空文字列でなし)。

- `i`: 大文字小文字を区別しない
- `s`: `.` が改行にも一致する
- `m`: `^` と `$` が行頭・行末に一致する
- `x`: パターン中の空白とコメント（`#` から行末）を無視する

パターンの中の `(?i)` `(?s)` `(?m)` `(?x)` でも指定できる。

## 位置

位置は0オリジンの文字数。負の値は末尾から数える(-1が最後の文字)。Windowsでは、BMP外の文字(絵文字など)は2文字として数える。ただしパターンの中では、サロゲートペアは1文字として扱われる(.や\[^a\]は絵文字全体に一致する)。一致の開始位置・終了位置がペアの途中になることはない。

## サブルーチン呼び出し

パターンの中の(?&名前) (?P\>名前) \g&lt;名前\>のようなサブルーチン呼び出しで、パターン内に定義(?&lt;名前\>...)が無い名前は、**辞書のエントリ`${名前}`の展開結果**がその名前のグループの中身として取り込まれる。エントリが存在しなければ、不正なパターンとして扱われる(エラーログが出て、空文字列が返る)。取り込まれた文字列の中でさらに別の名前を呼んでもよい。

取り込まれたグループは結果(エントリに格納されるグループ)には現れず、パターン自身の括弧のグループだけが数えられる。名前に使えるのは英数字・\_・日本語などで、.は使えない(名前空間の中のエントリは呼べない)。エントリが複数の単語を持つときは、通常の参照と同じくランダムに1つが選ばれる。

```
# 辞書
year : [0-9]{4}
date : "(?&year)-([0-9]{2})-([0-9]{2})"

=kis
regex_match "2026-10-18" "^(?&date)$" "" m;
# ${m} は 2026-10-18 を含む。パターンに括弧が無いので、グループは全体の1つだけ
=end
```

## エラー

オプションやパターンが不正なとき、マッチに時間がかかりすぎて打ち切ったとき(パターンによっては指数時間かかるため、入力に応じた回数でバックトラックを止める)は、ログにエラーを出し、空文字列を返す。
