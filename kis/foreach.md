# foreach

**Category:** 構文コマンド

## 書式

```
$(foreach エントリ1 エントリ2 文1)
```

## 戻り値

文1をエントリ2内の全単語について評価した結果

## 解説

エントリ2内の全単語を順にエントリ1にセットし、そのつど文1を評価する。文1に置換ブロックを用いる場合には、`$()`等で囲む。

## 使用例

```
$(set N 0 ; foreach i npw $(echo ${i}様、 ; inc N) ; echo 以上${N}名)
# npwエントリ内の人名を全て「様」をつけて呼び、最後に「以上n名」と
# 人数を表示
```
