# regex_split

**Category:** 正規表現

## 書式

```
$(regex_split エントリ1 文字列1 パターン [オプション [最大個数]])
```

## 戻り値

分割した要素の個数。エラーのときは空文字列

## 解説

文字列1をパターンにマッチした部分で分割し、エントリ1の内容を置き換えて順に格納する(splitと違い、以前の内容は消える)。最大個数が正のとき、要素数はその個数までで、残りは最後の要素に入る。先頭と末尾での空文字列へのマッチでは区切らない。パターンが空文字列なら、文字ごとに分割する。

## 使用例

```
=kis
regex_split items "a, b,c" ",\s*";
# 3が返り、itemsは「a」「b」「c」になる
=end
```
