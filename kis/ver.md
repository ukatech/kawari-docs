# ver

**Category:** その他

## 書式

```
$(ver 情報名)
```

## 戻り値

バージョン情報

## 解説

"華和梨"の情報を返す。「情報名」で欲しい情報を選択できる。

情報名が「license」の場合、"華和梨"のライセンス情報をログに出力する。情報名が「author」の場合、"華和梨"の開発者情報を返す。情報名を省略した場合、"華和梨"のバージョン情報を返す。バージョン情報のフォーマットは「基本名称\[.補助名称\[.補助名称\]\]/バージョン番号」。

## 使用例

**例("幸水"での実行例)**

```
echo-mode > $(ver)
KAWARI.kdt/8.2.0
```
