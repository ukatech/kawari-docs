# until

**Category:** 構文コマンド

## 書式

```
$(until 条件文 文1)
```

## 戻り値

文1の戻り値

## 解説

条件文を評価し、結果が偽ならば文1を評価する。この動作を、条件文の評価結果が偽である間、ずっと繰り返す。条件文、文1に置換ブロックを用いる場合には、`$()`等で囲む。

## 使用例

```
=kis
setstr A ${npw};
setstr B ${npw};
until $[ ${A} != ${B} ] $(
  setstr B ${npw};
);
# AエントリとBエントリが必ず異なるようにする
=end
```
