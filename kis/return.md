# return

**Category:** 構文コマンド

## 書式

```
$(return 戻り値)
```

## 戻り値

指定した戻り値

## 解説

関数から指定した戻り値で直ちに抜ける。戻り値は省略可能で、省略した場合、それまでの関数の出力が関数の戻り値となる。

## 使用例

```
=kis
function じゃんけん $(
  if $[ $@arg[1] == 1 ] $(
    return "ぐー";
  ) else if $[ $@arg[1] == 2 ] $(
    return "ちょき";
  ) else $(
    return "ぱー";
  );
);
=end
```
