# textappend

**Category:** ファイル操作

## 書式

```
$(textappend ファイル名 エントリ1 [エントリ2..])
```

## 戻り値

なし

## 解説

エントリ1、エントリ2…の全ての内容を、テキストファイル1に追記する。セキュリティの観点から、書き出すファイル名は相対パスのみである。エントリの内容は、添え字順に評価してその結果を書き出す。ファイルに書き出す際、添え字ごとに最後に改行する。textsaveとの違いは、テキストファイル1の以前の内容が残る点である。

Phase 9.0.0以降、追記する内容はUTF-8(BOMなし)で書き出される。既存のファイルが`Shift_JIS`であっても、UTF-8で追記される(1つのファイル内に文字コードが混在するので注意)。

## 使用例

```
=kis
textappend highscore.dat 新タイトル保持者名;
# highscore.datに、「新タイトル保持者名」エントリの内容を追記
=end
```
