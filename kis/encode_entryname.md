# encode_entryname

**Category:** 出力

## 書式

```
$(encode_entryname 文字列1)
```

## 戻り値

エントリ名に使用できる文字に変換した文字列

## 解説

指定文字列中のエントリ名に使用できない文字を変換し、エントリ名に使用できる文字列を返す。使用できない文字は、"\_"に変換する。エントリ名に使用できない文字については、KIS Programming Referenceの「3.華和梨文法」を参照のこと。

## 使用例

```
=kis
encode_entryname "「#」や「,」や「 」はエントリ名に使えません";
# "「_」や「_」や「_」はエントリ名に使えません"が返る。
=end
```
