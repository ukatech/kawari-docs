# move

**Category:** 辞書操作

## 書式

```
$(move エントリ1 エントリ2)
```

## 戻り値

なし

## 解説

エントリ1の内容を、すべてエントリ2に移す。実行後、エントリ1の内容は削除される。エントリ2の以前の内容はそのまま残り、エントリ1の内容をエントリ2に追加する。

## 使用例

```
ghost1 : さくら , まゆら , 奈留 , 理夢 , ${ghost2}
ghost2 : サンバーレイン , 毒子 , 花ちゃん

=kis
move ghost1 ghost3;

getcode ghost3;
# 「"さくら""まゆら""奈留""理夢"${ghost2}」が返る

size ghost1;
# 0が返る
=end
```
